## 🤖 AI Agent 통계 API 구현 (⭐️ 매우 중요)

### 개요
**목적:** AI Agent 서버가 사용자 분석에 필요한 모든 데이터를 한 번에 조회
**API 경로:** `GET /api/tracking/statistics/ai-agent`
**인증 방식:** x-token 헤더에 AES-GCM 암호화된 chartId 전달

### 구현 내용

#### 1. AI Agent 인증 가드 생성
**파일:** `src/tracking/guards/ai-agent-auth.guard.ts`

**특징:**
- JWT 인증 대신 x-token 헤더로 chartId 복호화
- AES-256-GCM 알고리즘 사용 (기존 CryptoUtil 활용)
- 복호화 성공 시 `req.chartId`에 저장

**인증 흐름:**
```
1. x-token 헤더 존재 확인
2. CryptoUtil.decrypt()로 AES-GCM 복호화
3. 복호화 성공 → req.chartId 설정 후 통과
4. 복호화 실패 → 401 Unauthorized
```

#### 2. AI Agent 통계 DTO 정의
**파일:** `src/tracking/dto/statistics/ai-agent-statistics.dto.ts`

**응답 구조:**

#### 3. StatisticsService.getAiAgentStatistics() 메서드
**파일:** `src/tracking/services/statistics.service.ts` (Line 1415)

**처리 순서:**
1. **chartId → userId 조회**

2. **외부 API 호출: 음식물과민증 검사 결과**

   - 타임아웃: 10초
   - 실패 시 빈 배열 반환 (계속 진행)

   - **뷰티**: totalScore, innerBeautyScore, outerBeautyScore, 답변별 점수

   - **간헐적단식**: startDateTime, endDateTime, fastingHours
   - **수면**: bedDateTime, wakeDateTime, sleepHours
   - **활동**: activityType, durationInMinutes, estimatedCalories

### 구현 내용

#### 1. CryptoUtil 클래스 (Python)
**암호화 알고리즘:** AES-256-GCM (Node.js와 동일)

**주요 기능:**
```python
class CryptoUtil:
    def encrypt(text: str) -> str:
        # 1. 16바이트 IV 생성
        # 2. AESGCM으로 암호화 (자동 인증태그 생성)
        # 3. IV + 암호문 결합
        # 4. Base64 인코딩

    def decrypt(encrypted_text: str) -> str:
        # 1. Base64 디코딩
        # 2. IV와 암호문 분리
        # 3. AESGCM으로 복호화
```

**키 관리:**
- 환경변수 `ENCRYPTION_KEY` 사용
- 키가 32바이트가 아니면 SHA256으로 해시
- Node.js의 CryptoUtil과 동일한 방식

#### 2. AiAgentApiClient 클래스
**기능:**
```python
client = AiAgentApiClient(base_url="http://localhost:10804")
result = client.get_statistics("TA11150002")
```

**처리 흐름:**
1. 차트ID를 AES-GCM으로 암호화
2. x-token 헤더에 암호화된 값 전달
3. API 호출 및 응답 처리
4. 에러 상황 로깅
