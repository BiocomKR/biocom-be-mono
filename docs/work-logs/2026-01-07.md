# 작업 로그 - 2026-01-07

## 1. 채팅 내역 조회 API 구현

### 요구사항
- AI 챗봇 대화 내역을 조회하는 API 필요
- 역방향 페이지네이션 (최신 메시지부터 조회, 스크롤 업 시 이전 메시지 로드)
- 한국어 날짜/시간 포맷

### 구현 내용

#### 엔드포인트
- **GET** `/api/chat/history`
- Query Parameters:
  - `page`: 페이지 번호 (기본값: 1, 최신 메시지부터)
  - `limit`: 페이지당 메시지 수 (기본값: 30, 최대: 100)

#### 응답 형식
```json
{
  "success": true,
  "data": {
    "messages": [
      {
        "text": "안녕! 오늘 뭐 먹었어?",
        "isUser": false,
        "date": "2026년 1월 5일",
        "time": "오후 8:45",
        "personaName": "메이브"
      }
    ],
    "page": 1,
    "limit": 30,
    "totalPage": 4,
    "isEndOfPage": false
  }
}
```

#### 역방향 페이지네이션 로직
```
총 120건, limit=30 기준:
- page=1: 91~120번 레코드 (최신 30건)
- page=2: 61~90번 레코드
- page=3: 31~60번 레코드
- page=4: 1~30번 레코드 → isEndOfPage: true
```

### 버그 수정

#### 1. KST 시간 계산 버그
- **문제**: 날짜가 하루 뒤로 표시됨 (1월 5일 → 1월 6일)
- **원인**: DB에 이미 KST로 저장되어 있는데 +9시간 변환 적용
- **수정**: KST 변환 로직 제거
```typescript
// Before (버그)
const kstDate = new Date(chat.createdAt.getTime() + 9 * 60 * 60 * 1000);

// After (수정)
const kstDate = chat.createdAt;
```

#### 2. 응답 키 이름 변경
- **변경**: `날짜`, `시간` → `date`, `time`
- **이유**: 프론트엔드 호환성
