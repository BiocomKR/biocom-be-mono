#### 3. 크론잡 신규 추가
**파일:** `src/cron/activate-challenges.cron.ts` (신규)

**실행 시각:** 매일 KST 00:00

**로직:**
```typescript
// 오늘 시작해야 하는 PENDING 챌린지 찾기
const pendingChallenges = await prisma.userChallenge.findMany({
  where: {
    status: 'PENDING',
    startDate: {
      lte: new Date(today + ' 00:00:00'),
      gte: new Date(today + ' 00:00:00')
    }
  }
});

// 각 챌린지를 ACTIVE로 전환
for (const challenge of pendingChallenges) {
  await prisma.$transaction(async (tx) => {
    // 1. UserChallenge ACTIVE로 변경
    await tx.userChallenge.update({
      where: { id: challenge.id },
      data: { status: 'ACTIVE' }
    });

    // 2. User를 CHALLENGER로 변경
    await tx.user.update({
      where: { id: challenge.userId },
      data: { status: 'CHALLENGER' }
    });

    // 3. Day 1 Progress 생성
    await tx.dailyProgress.create({
      data: {
        userChallengeId: challenge.id,
        day: 1,
        date: new Date(today)
      }
    });
  });
}
```
