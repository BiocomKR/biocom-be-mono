## ✅ 설계 완료

### 1. 하이브리드 구독 시스템 아키텍처

#### 결제 수단 분리
```
무형 상품 (디지털 콘텐츠):
- 결제 수단: IAP (Apple In-App Purchase / Google Play Billing)
- 이유: 앱스토어 정책 준수 (리젝 방지)
- 예시: 프리미엄 구독, 강의 이용권, 챌린지 이용권

유형 상품 (물리적 상품):
- 결제 수단: 토스 페이먼츠
- 이유: 수수료 절약 (IAP 30% vs 토스 2~3%)
- 예시: 영양제, 건강식품, 운동기구 등
```

### 2. API 엔드포인트 설계

#### 무형 상품 구독 (신규)
```
POST /shop/subscription/iap
Request:
{
  "receipt": "애플/구글 영수증",
  "productId": "com.biocom.premium",
  "platform": "APPLE" or "GOOGLE"
}

처리 로직:
1. 영수증 검증 (애플/구글 서버에 요청)
2. 응답에서 확인:
   - is_trial_period: true/false (무료 체험 여부)
   - expires_date: 만료일
   - transaction_id: 거래 ID
3. DB에 구독 저장 (paymentMethod: 'IAP_APPLE' or 'IAP_GOOGLE')
```

#### 유형 상품 구독 (기존 리팩토링)
```
POST /shop/subscription/toss
- 기존 POST /shop/subscription을 이동
- 토스 빌링키 자동결제
- paymentMethod: 'TOSS'
```

### 3. 구독 상품 특이사항

#### 무료 체험 정책
```
최초 1회: 0원 (30일 무료 체험)
이후: 9,900원 (30일 구독)
구독 취소: 환불 없음, 30일은 이용 가능
```

#### IAP 무료 체험(Free Trial) 동작 방식

**애플/구글 콘솔 설정**:
```
상품명: 바이브코딩 프리미엄 구독
상품 ID: com.biocom.premium
구독 기간: 1개월 (30일)
가격: 9,900원
무료 체험: 30일
```

**사용자 플로우**:
```
1. 앱에서 "구독하기" 버튼 클릭
   → IAP 결제창 표시
   → "첫 30일 무료, 이후 월 9,900원" 안내

2. 사용자가 결제 동의
   → 카드 정보 등록 (과금은 안 됨)
   → 즉시 구독 시작 (0원)

3. 30일 후 자동으로 9,900원 결제
   → 애플/구글이 자동 처리
   → 이후 매월 30일마다 9,900원 자동 결제

4. 사용자가 구독 취소
   → 30일은 그대로 이용 가능 (환불 없음)
   → 다음 갱신일에 자동 해지
```

**핵심 특징**:
- ✅ 첫 30일 0원, 이후 자동으로 9,900원 (요구사항 완벽 충족)
- ✅ 애플/구글이 자동 갱신 (백엔드 스케줄러 불필요)
- ✅ 취소해도 30일은 이용 가능 (환불 없음 정책)
- ✅ 앱스토어 정책 완벽 준수 (리젝 위험 없음)
- ❌ 애플/구글 수수료 30% (9,900원 → 실수령 6,930원)

#### 무료 체험 재사용 불가 정책

**애플/구글이 판단 (백엔드 제어 불가)**:
```
시나리오:
1월: 사용자가 구독 (0원, 무료 체험)
   → Apple ID: user@example.com으로 구독

2월: 구독 취소
   → 2월 말에 자동 해지

4월: 같은 Apple ID로 재구독 시도
   → 애플: "이 계정은 이미 무료 체험 사용함"
   → 즉시 9,900원 결제 (무료 체험 없음)
```

**정책**:
- Apple ID / Google 계정 기준으로 1회만 허용
- 백엔드나 앱에서 제어 불가능
- 애플/구글 서버가 자동으로 판단

**영수증 정보**:
```json
// 최초 구독 (무료 체험)
{
  "transaction_id": "1000000123456789",
  "product_id": "com.biocom.premium",
  "is_trial_period": true,  // ← 애플/구글이 판단
  "original_transaction_id": "1000000123456789",
  "expires_date": "2025-12-11",
  "purchase_date": "2025-11-11"
}

// 재구독 (유료)
{
  "transaction_id": "1000000999999999",
  "product_id": "com.biocom.premium",
  "is_trial_period": false,  // ← 이미 체험 사용
  "original_transaction_id": "1000000123456789",
  "expires_date": "2025-05-11",
  "purchase_date": "2025-04-11"
}
```

**무료 체험 다시 주는 방법**:
```
방법 1: 새 상품 등록
- com.biocom.premium_v2 생성
- 문제: 앱 업데이트 필요, 사용자 혼란

방법 2: Offer Codes (프로모션 코드)
- 애플/구글 콘솔에서 발급
- 문제: 코드 개수 제한, 수동 입력 불편

방법 3: 백엔드 무료 이용권 지급 (추천)
- POST /shop/items/claim
- "30일 프리미엄 이용권" 지급
- 문제: 자동 갱신 안 됨 (일회성)
```

### 8. 지연성알러지검사결과_조회 쿼리 튜닝 ⚡

**문제 발견**:
- 특정 API 느림 (13초)
- 원인: UNION ALL 89번 사용하는 괴물 쿼리

**튜닝 결과**:
- **실행 시간**: 13초 → 0.2초 ✅
- **개선율**: 98.5% (65배 빨라짐)
- **결과 정확성**: 완벽 일치 확인 ✅

**개선 방법**:
1. UNION ALL 89번 → UNPIVOT 1번으로 변경
2. NULL 값 처리 (ISNULL 사용)
3. ItemId 순차 매핑 (1~89)
4. 함수 호출 시 올바른 ItemId 전달

**UNPIVOT 핵심 개념**:
- 컬럼을 행으로 변환하는 관계형 연산자
- NULL 값 자동 제거 → ISNULL로 0 치환하여 해결
- 데이터 타입 통일 필수
- 코드 간결화 및 성능 개선

**비교**:
| 항목 | UNION ALL | UNPIVOT |
|------|-----------|---------|
| 코드 길이 | 200+ 줄 | 구조화된 CTE |
| 가독성 | ❌ 최악 | ✅ 명확 |
| 유지보수 | ❌ 지옥 | ✅ 쉬움 |
| 성능 | 13초 | 0.2초 |
| 확장성 | ❌ 어려움 | ✅ 쉬움 |
