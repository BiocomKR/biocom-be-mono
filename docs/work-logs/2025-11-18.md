**새로운 엔드포인트**: `POST /api/challenges/quick-start`

3. 티켓 확인 → 없으면 0원 자동 구매

### 3. 챌린지 활성화 스케줄러 버그 수정 🐛
**목적**: 시작일 도달 시 PENDING → ACTIVE 전환이 안 되는 문제 해결

#### 문제 원인
```typescript
// 기존 코드 (문제)
const today = new Date(); // 로컬 시간대 (UTC 또는 서버 시간대)
today.setHours(0, 0, 0, 0);
```
- `new Date()`는 로컬 시간대로 생성
- DB의 `start_date`는 KST로 저장
- **시간대 불일치로 인해 조회 실패**

#### 수정 내용
```typescript
// 수정 후
const today = getNowKST(); // KST 기준
today.setHours(0, 0, 0, 0);
```
