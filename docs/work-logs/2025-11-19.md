model UserConsent {

  updatedAt          DateTime  @updatedAt @map("updated_at")

### 4. 영양제 기록 API 구현 완료

**엔드포인트**: `POST /tracking/records/supplements`

**DTO (CreateSupplementRecordDto)**
```typescript
{
  date: string;        // YYYY-MM-DD 형식
  productId: number;   // 영양제 상품 ID
  count: number;       // 1-10 (실제로는 1-3 사용)
  imageUrl?: string;   // 사진 URL (조건부 필수)
}
```

**비즈니스 로직 (5단계 검증)**
1. **루틴 검증**: user_supplement_routine에 등록된 영양제인지 확인
   - 미등록 시: `ForbiddenException` ("루틴에 등록되지 않은 영양제는 기록할 수 없습니다.")

2. **상품 검증**: products 테이블에 존재하는 상품인지 확인

3. **일일 10회 제한**: 하루 최대 10개까지만 영양제 기록 가능
   - 초과 시: `BadRequestException` ("하루 최대 10회까지만 영양제를 기록할 수 있습니다.")

4. **사진 필수 여부**: 당일 첫 기록인지 확인
   - 첫 기록 && imageUrl 없음: `BadRequestException` ("당일 첫 영양제 기록 시 사진은 필수입니다.")
   - 첫 기록 아님: imageUrl 선택사항

5. **기록 생성**: user_records 테이블에 저장
