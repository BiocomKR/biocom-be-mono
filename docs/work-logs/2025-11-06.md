### 1. 강의 퀴즈 노출 로직 수정
**문제점**: 구독자에게도 퀴즈가 노출되고, 과거 퀴즈 포인트 지급 로직 부재

**해결 방법**:
- 퀴즈 노출 조건 3단계로 분리:
  1. **미래 퀴즈** (`currentDay < dayNumber`): 비노출, 잠금 메시지
  2. **당일 퀴즈** (`currentDay === dayNumber`): 노출, 200점 지급
  3. **과거 퀴즈** (`currentDay > dayNumber`): 노출, 0점 (복습용)
- 구독자는 모든 퀴즈 비노출 처리

**수정 파일**:
- `src/content/content.controller.ts:298-355` - 강의 상세 API 퀴즈 상태 로직
- `src/quiz/quiz-completion.service.ts:371-524` - 퀴즈 풀이 포인트 지급 로직
- `src/quiz/quiz-completion.controller.ts:66-98` - Swagger 문서 업데이트

**API 응답 구조**:
```typescript
{
  lectureQuizzes: [...],  // 퀴즈 데이터 (비노출 시 빈 배열)
  quizStatus: {
    available: true/false,       // 퀴즈 이용 가능 여부
    openDay: 15,                 // 오픈 일차
    message: "15일차에 오픈됩니다",
    canEarnPoints: true/false    // 포인트 획득 가능 여부
  }
}
```

### 3. 퀴즈 재시도 허용
**문제점**: `quiz_attempts` 테이블에 UNIQUE 제약으로 인해 같은 퀴즈를 다시 풀 수 없음

**해결 방법**:
- `quiz_attempts` 테이블의 `(user_id, quiz_id)` UNIQUE 제약 제거
- 포인트는 Service 로직에서 최초 1회만 지급 제어

**마이그레이션**:
```sql
-- prisma/migrations/20251106_remove_quiz_attempts_unique.sql
ALTER TABLE quiz_attempts DROP CONSTRAINT IF EXISTS quiz_attempts_user_id_quiz_id_key;
```

**효과**:
- 언제든 퀴즈 재시도 가능 ✅
- 인덱스는 유지되어 조회 성능 유지 ✅

### 4. 강의-상품 연동 개선

#### 4-1. lecture_products 테이블에 타임스탬프 추가
**문제점**: 날짜 컬럼 부재로 데이터 변경 이력 추적 불가

**해결 방법**:
- `created_at`, `updated_at` 컬럼 추가
- PostgreSQL 트리거로 `updated_at` 자동 업데이트 설정

**마이그레이션**:
```sql
-- prisma/migrations/20251106_add_lecture_products_timestamps.sql
ALTER TABLE lecture_products
ADD COLUMN created_at TIMESTAMP(6) DEFAULT CURRENT_TIMESTAMP,
ADD COLUMN updated_at TIMESTAMP(6) DEFAULT CURRENT_TIMESTAMP;

CREATE TRIGGER trigger_lecture_products_updated_at
    BEFORE UPDATE ON lecture_products
    FOR EACH ROW
    EXECUTE FUNCTION update_lecture_products_updated_at();
```

## 🎯 핵심 인사이트

### 1. 퀴즈 노출 로직 설계
**3단계 조건 분기**:
- 미래 퀴즈: 비노출 (동기 부여)
- 당일 퀴즈: 노출 + 포인트 (보상)
- 과거 퀴즈: 노출 + 무보상 (복습)

- 운영: 추적성 보장 (파일 로그)

### 3. 데이터 무결성
- 재시도 허용 vs 중복 방지 → 비즈니스 로직으로 제어
- DB 제약은 최소화, 유연성 확보

### 4. 환경 설정 동기화
- 로컬 `.env`와 GKE ConfigMap 일치 필수
- 누락 시 운영 환경 장애 발생 가능
