## 📊 데이터베이스 구조 분석

### 핵심 테이블 8개

#### 1. Product (상품)
- **위치**: `prisma/schema.prisma:548-617`
- **주요 컬럼**:
  - `productType`: SINGLE(단품), SET(세트)
  - `categoryCode`: SUPPLEMENT, HEALTH_FOOD, CHALLENGE, SUBSCRIPTION
  - `price`, `originalPrice`, `discountRate`
  - `shippingFee`, `shippingPolicy` (FREE/PAID/CONDITIONAL)
  - `pointRate`: 적립 포인트율 (%)
  - `maxOrderQty`: 1인당 최대 주문 수량
  - `metadata`: JSONB (챌린지 정보: totalDays 등)

#### 2. Cart (장바구니)
- **위치**: `prisma/schema.prisma:668-680`
- **특징**: 사용자당 1개 (`userId` unique)

#### 3. CartItem (장바구니 아이템)
- **위치**: `prisma/schema.prisma:684-706`
- **주요 컬럼**:
  - `stockCheckedAt`: 재고 확인 시각
  - `stockAvailable`: 재고 가용 여부
  - **Unique 제약**: `cartId_productId` (중복 방지)

#### 4. Order (주문)
- **위치**: `prisma/schema.prisma:710-773`
- **주문번호 형식**: `O + YYYYMMDDHHMMSS + 3자리랜덤`
- **주요 컬럼**:
  - `status`: 주문 상태 (PENDING_PAYMENT → PAID → PREPARING → SHIPPED → DELIVERED → COMPLETED)
  - `inventoryStatus`: 재고 처리 상태 (현재 사용 안 함)
  - `totalProductPrice`, `totalDiscount`, `shippingFee`, `pointUsed`, `totalAmount`
  - `recipientName`, `recipientMobile`, `address`, `addressDetail` (암호화)
  - `orderedAt`, `paidAt`, `shippedAt`, `deliveredAt`, `completedAt`, `cancelledAt`

#### 5. OrderItem (주문 상품)
- **위치**: `prisma/schema.prisma:777-802`
- **특징**: 주문 시점 스냅샷 (상품명, 가격 보존)

#### 6. OrderStateLog (주문 상태 로그)
- **위치**: `prisma/schema.prisma:806-824`
- **특징**: 모든 상태 변경 이력 추적

#### 7. Payment (결제)
- **위치**: `prisma/schema.prisma:828-866`
- **주요 컬럼**:
  - `pgProvider`: TOSS (토스페이먼츠)
  - `pgTransactionId`: PG사 거래번호
  - `paymentMethod`: CARD, VIRTUAL_ACCOUNT, BANK_TRANSFER, MOBILE, EASY_PAY
  - `status`: READY → PENDING → COMPLETED / FAILED / CANCELLED
  - `amount`: PG사 결제 금액
  - `pointAmount`: 포인트 결제 금액

#### 8. Refund (환불)
- **위치**: `prisma/schema.prisma:870-914`
- **주요 컬럼**:
  - `refundType`: CANCEL(취소), RETURN(반품)
  - `status`: REQUESTED → COMPLETED / REJECTED
  - `tossCancelId`: 토스페이먼츠 취소 ID

```typescript
  recipientName: CryptoUtil.encrypt(dto.shippingAddress.recipientName),
  recipientMobile: CryptoUtil.encrypt(dto.shippingAddress.recipientPhone),
  address: CryptoUtil.encrypt(dto.shippingAddress.address),
  addressDetail: dto.shippingAddress.addressDetail
    ? CryptoUtil.encrypt(dto.shippingAddress.addressDetail)
    : null,
}

// 조회 시
return {
  ...order,
  recipientName: CryptoUtil.decrypt(order.recipientName),
  recipientMobile: CryptoUtil.decrypt(order.recipientMobile),
  address: CryptoUtil.decrypt(order.address),
  addressDetail: order.addressDetail
    ? CryptoUtil.decrypt(order.addressDetail)
    : null,
}
```

### KST 날짜/시간 처리
**유틸**: `src/common/utils/kst-date.util.ts`

#### 필수 사용
- **절대 금지**: `new Date()` 직접 사용
- **필수 사용**: `getNowKST()`

#### 이유
- Prisma ORM이 모든 Date 객체를 UTC로 변환
- `Date.UTC()`로 KST 값을 생성하여 Prisma의 UTC 변환 우회

```
PENDING_PAYMENT (결제 대기)
    ↓ 결제 완료
PAID (결제 완료)
    ↓ 관리자: 배송 준비
PREPARING (배송 준비 중)
    ↓ 관리자: 배송 시작
SHIPPED (배송 중)
    ↓ 관리자: 배송 완료
DELIVERED (배송 완료)
    ↓ 고객: 구매 확정 (또는 7일 후 자동)
COMPLETED (구매 확정) → 포인트 1% 지급

    ↓ (언제든지)
CANCELLED (취소) → 포인트 복구
```
