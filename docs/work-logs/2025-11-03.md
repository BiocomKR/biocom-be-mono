- **수정**:
  ```typescript
  // 기존 (잘못됨)
  const questionScore = Math.round((item.score / 5 * 100));

  // 수정 (올바름)
  dayInnerScore += item.score;  // 점수 그대로 합산
  ```

- **평균 계산 로직 수정**:
  ```typescript
  // 기존 (잘못됨)
  const innerScore = Math.round(totalInnerScore / 7);  // 무조건 7로 나눔

  // 수정 (올바름)
  const daysCount = weekDates.length;
  const innerScore = daysCount > 0 ? Math.round(totalInnerScore / daysCount) : 0;
  ```

- **최종 계산 공식**:
  - 이너뷰티 평균 = (전체 이너뷰티 합) / 검색일 수
  - 아우터뷰티 평균 = (전체 아우터뷰티 합) / 검색일 수
  - 종합 평균 = (이너뷰티 평균 + 아우터뷰티 평균) / 2
  - 일별 점수 = 해당일 4개 질문 점수 합

## 주요 이슈 및 해결

### 이슈 1: Prisma date 필드 타입 에러
- **문제**: `Invalid value for argument 'date': premature end of input. Expected ISO-8601 DateTime.`
- **원인**: schema.prisma에서 `date DateTime @db.Date`인데 문자열 직접 비교
- **해결**: `new Date(date)` 변환 추가

### 이슈 2: createdAt 필수 필드 누락
- **문제**: `Argument 'createdAt' is missing.`
- **원인**: schema에 `@default(now())` 없음
- **해결**: `createdAt: getNowKST()` 명시적 추가

### 이슈 3: 통계 데이터가 0으로 나옴
- **문제**: DB에서 가져온 date는 Date 객체인데 문자열과 직접 비교
- **해결**: `r.date.toISOString().split('T')[0] === date` 변환 후 비교

### 이슈 4: 점수가 비정상적으로 큼 (375점 등)
- **문제**: 25점을 5점 기준 환산 공식 적용 (25/5*100 = 500점)
- **해결**: 점수 그대로 합산, 환산 제거

### 이슈 5: 무조건 7일로 나눔
- **문제**: 검색 기간이 5일이든 7일이든 무조건 7로 나눔
- **해결**: `weekDates.length`로 실제 검색일 수만큼 나눔
