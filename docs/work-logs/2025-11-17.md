### 2. 과거 미션 수행 로직 개선
**목적**: 놓친 미션을 나중에라도 수행할 수 있도록 허용 (단, 포인트 0점)

#### 변경된 로직
```typescript
// 기존: 당일 미션만 수행 가능
if (challengeMission.day !== currentDay) {
  throw new BadRequestException('오늘의 미션이 아닙니다');
}

// 변경: 과거 미션 허용, 미래 미션만 차단
if (challengeMission.day > currentDay) {
  throw new BadRequestException('아직 수행할 수 없는 미션입니다');
}

// 포인트 지급 조건 추가
const isOnScheduledDay = challengeMission.day === currentDay;
const pointsEarned = (isCompleted && isOnScheduledDay) ? challengeMission.points : 0;
```

- `src/mission/mission-completion.service.ts` (lines 85-88, 270-272)

### 3. 새로운 API 추가

#### 3-1. 완료한 미션 목록 조회
**엔드포인트**: `GET /api/missions/completed`

**파라미터**:
- `startDate` (required): 시작일 (YYYY-MM-DD)
- `endDate` (required): 종료일 (YYYY-MM-DD)

**응답 예시**:
```json
{
  "success": true,
  "data": {
    "dateRange": { "startDate": "2025-01-01", "endDate": "2025-01-10" },
    "dayRange": { "startDay": 1, "endDay": 10 },
    "missions": {
      "1": [
        {
          "challengeMissionId": 123,
          "missionName": "자기선언문 작성",
          "pointsEarned": 100,
          "completedAt": "2025-01-15T10:30:00Z"
        }
      ]
    },
    "totalCount": 15
  }
}
```

#### 3-2. 놓친 미션 목록 조회
**엔드포인트**: `GET /api/missions/missed`

**파라미터**:
- `startDate` (required): 시작일 (YYYY-MM-DD)
- `endDate` (required): 종료일 (YYYY-MM-DD)

**응답 예시**:
```json
{
  "success": true,
  "data": {
    "dateRange": { "startDate": "2025-01-01", "endDate": "2025-01-10" },
    "dayRange": { "startDay": 1, "endDay": 9 },
    "missions": {
      "2": [
        {
          "challengeMissionId": 124,
          "missionName": "물 2L 마시기",
          "originalPoints": 50,
          "currentPoints": 0
        }
      ]
    },
    "totalCount": 5,
    "message": "과거 미션만 조회됩니다"
  }
}
```

**특징**:
- 미래 미션은 자동 제외 (currentDay - 1까지만 조회)
- 놓친 미션은 지금 수행해도 0점

#### 3-3. 자기선언문/칭찬내역 조회
**엔드포인트**: `GET /api/missions/self-records`

**파라미터**: 없음 (활성화된 챌린지 기준)

**응답 예시**:
```json
{
  "success": true,
  "data": [
    {
      "type": "DECLARATION",
      "day": 1,
      "contents": "자기 선언문 내용이 들어갑니다.",
      "completedAt": "2025-01-15T10:30:00Z",
      "pointsEarned": 100
    },
    {
      "type": "SELF_PRAISE",
      "day": 10,
      "contents": "칭찬 내용이 들어갑니다.",
      "completedAt": "2025-01-24T14:20:00Z",
      "pointsEarned": 100
    }
  ]
}
```

**구현 로직**:
1. `missions` 테이블에서 `record_type IN ('DECLARATION', 'SELF_PRAISE')` 조회
2. `challenge_missions`에서 해당 미션의 `challengeMissionId` 획득
3. `user_missions`에서 `metadata.contents` 추출
4. day 순서대로 정렬 반환

**적용 파일**:
- `src/mission/mission-completion.service.ts` - `getCompletedMissions()`, `getMissedMissions()`, `getRecords()` 메서드 추가
- `src/mission/mission.controller.ts` - 3개 엔드포인트 추가

## 🐛 발생한 문제 및 해결

### 문제 1: Prisma Client 타입 불일치
**증상**: `Property 'userMission' does not exist on type 'PrismaService'`

**원인**:
- DB는 `user_missions` 테이블로 변경됨
- Prisma schema는 수정되었으나 Client가 재생성되지 않음
- PrismaService getter가 업데이트되지 않음

**해결**:
1. `prisma/schema.prisma` 재확인 및 수정
2. `npx prisma generate` 실행
3. `src/common/services/prisma.service.ts`에서 `get userMission()` 추가
4. 모든 서비스 파일에서 `missionAttempt` → `userMission` 변경

### 문제 2: 엔드포인트 명명 모호성
**증상**: `/api/missions/records`가 모든 미션 기록을 조회하는 것처럼 보임

**해결**: `/api/missions/self-records`로 변경하여 자기선언문/칭찬내역만 조회함을 명확히 함
