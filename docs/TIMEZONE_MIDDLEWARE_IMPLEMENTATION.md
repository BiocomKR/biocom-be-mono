# 시간대 자동 변환 미들웨어 구현 완료

## 구현 일시
2025-08-01

## 구현 내용
Prisma Extension을 통해 모든 날짜/시간 필드의 자동 시간대 변환 구현

### 핵심 기능
1. **쓰기 작업 (create, update 등)**
   - 입력값: 한국 시간 (KST)
   - DB 저장: UTC로 자동 변환 (-9시간)
   
2. **읽기 작업 (find 등)**
   - DB 값: UTC
   - 반환값: 한국 시간으로 자동 변환 (+9시간)

### 구현 파일
- `/src/common/services/prisma.service.ts` - Prisma Extension 설정
- `/src/common/utils/timezone.util.ts` - 시간대 변환 유틸리티

### 작동 원리
```typescript
// 예시: 이벤트 생성
const event = await prisma.event.create({
  data: {
    startDate: new Date('2025-08-01T09:00:00'),  // KST 입력
    // ... 기타 필드
  }
});

// DB에는 UTC로 저장됨: 2025-08-01T00:00:00Z
// 하지만 반환값은 KST: 2025-08-01T09:00:00
```

### 장점
1. **투명성**: 개발자가 시간대 변환을 신경쓸 필요 없음
2. **일관성**: 모든 모델, 모든 작업에 자동 적용
3. **안전성**: 실수로 인한 시간대 오류 방지
4. **유지보수성**: 한 곳에서 중앙 집중 관리

### 주의사항
1. 모든 날짜는 한국 시간 기준으로 작업
2. Raw Query 사용 시에는 수동 변환 필요
3. 클라이언트도 한국 시간 기준으로 날짜 전송 필요

### 테스트 완료
- 입력 시간과 DB 저장값 비교 확인
- Prisma 조회 시 KST 변환 확인
- 기존 date.util.ts와 호환성 확인

## 결론
이제 개발자는 시간대 변환을 전혀 신경쓰지 않고 모든 날짜를 한국 시간으로 다룰 수 있습니다.
