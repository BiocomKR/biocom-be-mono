# 미션-퀴즈 구조 개선 TODO

## 현재 상황
- 미션 테이블에 "퀴즈 풀기" (code: QUIZ)가 존재
- 동시에 별도의 Quiz/EventQuiz 시스템도 존재
- 두 시스템이 중복/혼재되어 있음

## 히스토리
1. 최초: 챌린지 단독 프로세스에 퀴즈가 미션으로 포함
2. 개편: 이벤트 통합 개념으로 전환하며 Quiz/EventQuiz 별도 시스템 구축
3. 현재: 레거시(미션 내 퀴즈)와 신규(별도 퀴즈 시스템) 공존

## 잠재적 요구사항
기획팀에서 다음과 같은 요구사항이 나올 가능성:
- "오늘의 퀴즈 1개 풀기" (일반 일일 퀴즈)
- "건강 상식 퀴즈 3개 연속 정답" (미션형 퀴즈 챌린지)
- "퀴즈 정답률 80% 달성" (도전 과제)
- "친구와 퀴즈 대결하기" (소셜 미션)

## 개선 방향 (기획팀 확인 후 결정)

### 옵션 1: 완전 분리
- 미션에서 퀴즈 관련 코드 제거
- 모든 퀴즈는 Quiz/EventQuiz로만 관리
- 장점: 구조 명확
- 단점: 유연성 감소, 데이터 마이그레이션 필요

### 옵션 2: 역할 구분하여 공존
- 일반 퀴즈: Quiz/EventQuiz 시스템
- 특수 미션형 퀴즈: Mission 시스템
- 미션 코드로 구분 (QUIZ vs QUIZ_CHALLENGE 등)
- 장점: 유연성, 다양한 요구사항 대응 가능
- 단점: 관리 포인트 2개
