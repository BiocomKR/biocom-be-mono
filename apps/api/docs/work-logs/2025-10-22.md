## ✅ 완료 작업

### 1. 데일리 미션 API 구현

#### API 엔드포인트
- `GET /api/missions/daily` - 오늘의 1일1미션 조회

#### 구현 내용
- `daily_missions` 테이블에서 현재 챌린지 일차에 해당하는 미션 조회
- `challenge_missions` 테이블과 연결하여 완료 여부 확인
- `mission_attempts` 테이블에서 시도 횟수 카운트

#### 응답 예시
```json
{
  "success": true,
  "data": {
    "currentDay": 7,
    "mission": {
      "id": 9,
      "challengeMissionId": 9,
      "dailyMissionId": 22,
      "title": "햇빛 보며 산책하기",
      "description": "오늘은 햇살 아래를 걸어볼까요?...",
      "verifyType": "PHOTO",
      "imageUrl": "https://cdn.imweb.me/...",
      "reason": "햇빛은 비타민 D 생성을 돕고...",
      "method": "산책 중 자연 풍경이나 셀카 사진을 공유해주세요.",
      "points": 100,
      "dailyLimit": 1,
      "current": 0,
      "isCompleted": false
    }
  }
}
```

### 2. 데일리 퀴즈 API 구현

#### API 엔드포인트
- `GET /api/quizzes/daily` - 오늘의 퀴즈 조회
- `POST /api/quizzes/:id/complete` - 퀴즈 답변 제출

#### 구현 내용
- `quizzes` 테이블에서 현재 챌린지 일차에 해당하는 퀴즈 조회
- 조회 시 `correctAnswer`는 숨김 (정답은 서버에서만 확인)
- 답변 제출 시:
  - `user_records` 테이블에 퀴즈 기록 저장
  - `mission_attempts` 테이블에 시도 기록 저장
  - 정답인 경우에만 포인트 적립
  - 오답이면 재시도 가능, 정답 맞추면 더 이상 시도 불가

#### 퀴즈 조회 응답 예시
```json
{
  "success": true,
  "data": {
    "currentDay": 7,
    "quiz": {
      "id": 7,
      "question": "이너뷰티란 무엇인가요?",
      "options": [
        "외적인 아름다움만 추구하는 것",
        "내면의 건강과 아름다움을 추구하는 것",
        "화장품만 사용하는 것",
        "다이어트만 하는 것"
      ],
      "points": 200
    }
  }
}
```

#### 퀴즈 완료 요청/응답 예시
**요청**:
```json
{
  "selectedAnswer": 2
}
```

**응답**:
```json
{
  "success": true,
  "data": {
    "selectedAnswer": 2,
    "correctAnswer": 2,
    "isCorrect": true,
    "explanation": "이너뷰티는 내면의 건강과 아름다움을 추구하는 개념으로...",
    "pointsEarned": 200,
    "answeredAt": "2025-10-22T12:00:00.000Z"
  }
}
```

### 3. 미션 완료 처리 페이로드 정리

#### API 엔드포인트
- `POST /api/missions/:challengeMissionId/complete`

#### 미션 타입별 페이로드

##### 1) 사진 인증형 미션 (PHOTO)
```json
{
  "fileUploadId": 123
}
```
- 예: 햇빛 보며 산책하기, 10분 스트레칭 등

##### 2) 기록형 미션 (RECORD)
```json
{
  "value": "8",
  "unit": "시간"
}
```
- 예: 수면 시간 기록, 물 섭취량 기록 등

##### 3) 텍스트 인증형 (TEXT)
```json
{
  "metadata": {
    "note": "오늘 감사한 일 3가지..."
  }
}
```
- 예: 아침 감사 기록

##### 4) 텍스트+사진 인증형 (복합)
```json
{
  "metadata": {
    "fileUploadId": 123,
    "note": "오늘 감사한 일 3가지..."
  }
}
```

### 3. 완료 여부 판단 로직
**테이블**: `mission_attempts`

**로직**:
```typescript
// 오늘 해당 미션을 몇 번 시도했는지 카운트
const todayAttempts = await prisma.missionAttempt.count({
  where: {
    userId,
    challengeMissionId,
    day: currentDay
  }
});

// 시도 횟수가 dailyLimit 이상이면 완료
const isCompleted = todayAttempts >= mission.dailyLimit;
```

### 4. 퀴즈 재시도 로직
- **정답을 맞춘 경우**: 더 이상 시도 불가
- **오답인 경우**: 계속 재시도 가능
- `attemptNumber`는 자동 증가 (1, 2, 3...)
- 정답 맞출 때만 포인트 적립

## 🔄 추가 작업 (오후)

### 4. API 일관성 확보 및 데이터 구조 개선

#### 문제점 발견
1. **퀴즈 API 불일치**: 미션은 `challengeMissionId` 사용, 퀴즈는 `quiz.id` 사용
2. **user_records 데이터 불완전**: 역추적에 필요한 정보 부족

#### 해결 방안
**핵심 설계 원칙**: "챌린지 중심의 조립식 구조 + user_records만으로 완벽한 역추적"

### 5. 퀴즈 API challengeMissionId 사용하도록 변경

#### 변경 내용
**API 엔드포인트**:
- 변경 전: `POST /api/quizzes/:id/complete`
- 변경 후: `POST /api/quizzes/:challengeMissionId/complete`

**퀴즈 조회 응답에 challengeMissionId 추가**:
```json
{
  "quiz": {
    "id": 7,
    "challengeMissionId": 123,  // 추가됨
    "question": "...",
    "options": [...],
    "points": 200
  }
}
```

**퀴즈 완료 처리 로직**:
```typescript
// 변경 전: quiz.id로 조회 → 활성 챌린지 찾기 → challengeMission 찾기
// 변경 후: challengeMissionId로 직접 조회 → quiz 특정 (missionId + day)
```

#### 장점
1. 미션/퀴즈 API 일관성 확보
2. 사용자가 여러 챌린지 동시 진행 시에도 명확히 구분
3. 불필요한 쿼리 감소

### 6. user_records metadata 구조 개선

#### 개선 원칙
**"challengeMissionId + 실제 컨텐츠 ID 모두 저장"**

- `challengeMissionId`: 챌린지 컨텍스트 (productId, missionId, day 역추적)
- `quizId` / `dailyMissionId` / `contentId`: 실제 컨텐츠 특정

#### 퀴즈 기록 구조

**변경 전**:
```json
{
  "recordType": "QUIZ",
  "metadata": {
    "quizId": 7,
    "question": "...",
    "selectedAnswer": 2,
    "isCorrect": true,
    "pointsEarned": 200
  }
}
```

**변경 후**:
```json
{
  "recordType": "QUIZ",
  "metadata": {
    // 챌린지 컨텍스트
    "challengeMissionId": 123,
    "missionId": 19,
    "day": 7,
    "productId": 38,
    "productName": "이너뷰티 챌린지",

    // 실제 퀴즈 컨텐츠
    "quizId": 7,
    "question": "이너뷰티란?",
    "options": ["...", "..."],
    "selectedAnswer": 2,
    "correctAnswer": 2,
    "isCorrect": true,
    "explanation": "...",
    "pointsEarned": 200
  }
}
```

#### 미션 기록 구조 (DAILY_MISSION)

### 7. 컨텐츠 특수 케이스

**컨텐츠는 challengeMissionId가 선택사항**:
- 챌린지 참여자 → challengeMissionId 있음
- 구독자 → challengeMissionId 없음 (contentId만)

```json
// 챌린지 참여자
{
  "recordType": "DAILY_CONTENT",
  "userChallengeId": 1,
  "metadata": {
    "challengeMissionId": 150,  // 있음
    "contentId": 25,
    "title": "...",
    "viewDuration": 120
  }
}

// 구독자
{
  "recordType": "CONTENT_VIEW",
  "userChallengeId": null,
  "metadata": {
    "challengeMissionId": null,  // 없음
    "contentId": 25,
    "title": "...",
    "viewDuration": 120
  }
}
```
