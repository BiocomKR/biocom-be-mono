## 1️⃣ 쇼핑몰 API 보유 여부 확인

### 작업 내용
형님의 요청으로 쇼핑몰 기능 중 쿠폰과 포인트 API 존재 여부 확인

### 확인 결과

#### ✅ 쿠폰 API
**위치**: `src/coupons/controllers/coupon.controller.ts`

1. **보유 쿠폰 목록 조회**
   - 엔드포인트: `GET /coupons`
   - 기능: 사용자가 보유한 모든 쿠폰 조회 (만료 시간, 상태 포함)

2. **상품별 사용 가능한 쿠폰 조회**
   - 엔드포인트: `GET /coupons/available/:productId`
   - 기능: 특정 상품에 사용 가능한 쿠폰과 예상 할인 금액 조회

3. **쿠폰 유효성 검증**
   - 엔드포인트: `GET /coupons/:userCouponId/validate`
   - 기능: 특정 상품에 대해 쿠폰 사용 가능 여부 검증

4. **쿠폰 상세 정보 조회**
   - 엔드포인트: `GET /coupons/:userCouponId`

5. **쿠폰 사용**
   - 엔드포인트: `POST /coupons/:userCouponId/use`
   - 기능: 주문 시 쿠폰 사용 처리 (내부 시스템용)

#### ✅ 포인트 API
**위치**: `src/point/point.controller.ts`

1. **포인트 잔액 조회**
   - 엔드포인트: `GET /points/balance`
   - 기능: 현재 로그인한 사용자의 포인트 잔액 조회

2. **포인트 거래 내역 조회**
   - 엔드포인트: `GET /points/history`
   - 기능: 포인트 적립/차감 내역 조회 (페이지네이션 지원)

3. **포인트 차감**
   - 엔드포인트: `POST /points/deduct`

4. **아임웹 포인트 이관**
   - 엔드포인트: `POST /points/transfer/to-imweb`
   - 기능: 현재 사용자 포인트를 아임웹 쇼핑몰로 이관

5. **아임웹에서 포인트 가져오기**
   - 엔드포인트: `POST /points/transfer/from-imweb`
