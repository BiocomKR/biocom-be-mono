## 5. 🚨 미결정 사항 (중요!)

### 5.1 날짜 계산 기준점 논의 필요

**현재 구현**:
```
신청일 → 챌린지 시작일 선택 → 배송도착일 계산 → 배송시작일 계산
```

**대안**:
```
신청일 → 배송시작일 계산 → 배송도착일 계산 → 챌린지 시작일 계산
```

**왜 논의가 필요한가?**
- 현재: 챌린지 시작일(월요일)을 먼저 정하고 배송일을 역산
  - 장점: 사용자가 "언제 시작할지" 명확하게 선택
  - 단점: 배송시작일이 과거가 될 수 있음 (주말 신청 케이스)

- 대안: 배송시작일(신청일 기준)을 먼저 정하고 챌린지 시작일을 순산
  - 장점: 배송 준비 기간을 확실하게 확보
  - 단점: 챌린지 시작일이 유동적으로 변할 수 있음

### 5.2 검토 사항
1. 비즈니스 요구사항: 사용자가 선택하는 것은 "챌린지 시작일"인가 "배송 시작일"인가?
2. 배송 준비 최소 일수: 며칠이 필요한가?
3. 주말 신청 처리: 주말에 신청하면 배송시작일이 과거가 되는데 괜찮은가?

**결정 보류**: 추가 논의 후 로직 확정 필요

**문제점**:
