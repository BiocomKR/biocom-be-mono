## 5. 🚨 영양제 루틴 데이터 복구 (긴급)

### 문제
- 사용자 영양제 루틴 데이터가 전체적으로 꼬여버림
- `user_supplement_routines` 테이블과 `user_records` 테이블 불일치

### 복구 작업

#### 5-1. 형님 수작업
- `user_supplement_routines` 테이블 수동 정리 완료

#### 5-2. API 작업 (user_records 테이블)

**Step 1: userId=1 테스트**
```sql
-- 기존 SUPPLEMENT 레코드 삭제
DELETE FROM user_records
WHERE user_id = 1 AND record_type = 'SUPPLEMENT';
-- 결과: 139건 삭제
```

**Step 2: userId=1 레코드 재생성**
- 스크립트: `scripts/create-weekly-supplement-prod.js`
- 결과: 21건 생성 (3개 영양제 × 7일)
  - 바이오 밸런스 (productId=90)
  - 클린 밸런스 (productId=91)
  - 영데이즈 (productId=93)

**Step 3: 전체 사용자 SUPPLEMENT 레코드 삭제 (userId=1 제외)**
- 형님 수작업으로 직접 삭제

**Step 4: 전체 사용자 레코드 재생성**
- 스크립트: `scripts/create-weekly-supplement-all.js`
- 대상: 43명 (userId 5~47, userId=1 제외)
- 결과: **903건 생성** (43명 × 3개 영양제 × 7일)
- 기간: 2025-12-29 (월) ~ 2026-01-04 (일)

### 생성된 스크립트 파일
| 파일명 | 용도 |
|--------|------|
| `scripts/create-weekly-supplement.js` | 개발 DB용 (사용 안함) |
| `scripts/create-weekly-supplement-prod.js` | 운영 DB - 단일 사용자 테스트용 |
| `scripts/create-weekly-supplement-all.js` | 운영 DB - 전체 사용자 일괄 생성 |
